## 主题识别与颜色示意

- 六个主题补上 OpenMoji 15.1.0 的动物足印、桃、调色盘、数字、家人和自然图标，
  不再全部显示相同的黄色占位块。图标不覆盖中文主题名或英文名称；缺资源时回退到原字形卡。
- 六种颜色统一使用同尺寸、同轮廓的色圆。白色有黑色外圈，在浅色背景上也能辨认；
  不再让猫、辣椒、柠檬或天空等额外物体干扰颜色词义。保留原字音、中文、拼音和英文。
- 《找朋友》使用 Gustavo Fring 的三名儿童牵手照片，替换成人商业会面；保留全画面，不暗示照片人物演唱歌曲。
- 《画蛇添足》使用轮廓简洁的蛇插画，替换蟒蛇头部特写；仅表现故事角色，不冒充故事完整分镜。
- OpenMoji 使用官方固定版本的 618×618 RGBA PNG，原图不修改，透明底与轮廓保留。
  它们是插画，不登记为真人照片。图形遵循 CC BY-SA 4.0，About 中保留 OpenMoji 署名及逐项来源。
- 全部素材在开发时下载并随 APK 打包；应用不增加网络权限、在线图库或第三方运行时依赖。
  动态主题图资源也纳入 Release keep 规则。

## 接入约束

文化详情的现有标题卡经确认加入照片，汉字、标题、副标题、摘要、全文与播放/返回入口保留。
照片使用固定高度、fitCenter 保留完整画面，不把照片裁切成另一个语义；图片为装饰性主题素材，
不重复朗读标题。解码在既有 diskIO 执行器完成，主线程仅绑定结果；重复 render 不重复解码。
缺图、占位图、不能解码的资源回退为原汉字卡；过期请求及已结束/销毁页面的回调不绑定图片。
动态 ill_culture_* 资源与 ill_word_* 一起保留在资源压缩后的 Release APK 中。

当前文化封面为 9 张 CC0 摄影、1 张 Pexels 儿童牵手摄影和 1 张 OpenMoji 蛇插画，作者及原始来源逐项保存在清单和 About 中。神话、故事与歌曲
使用主题照片，不将其宣称为事件实拍，不生成假情景，也不改变原文本版本。具体主题为：
星空、两只老虎、白萝卜、儿童牵手、月亮、兔子、陆龟、蛇、月亮、白鹅、春日樱花。
“守株待兔”与“龟兔赛跑”照片分别表现故事角色之一，而非声称拍到事故或比赛。
筛选中曾发现名为 White Radish 的照片实际是白菜，已剔除；咏鹅采用白鹅，未采用灰色雁。
这些照片尚需 Android 设备上的呈现验收；静态资源或构建检查不能取代该验收。

- 保持 words.json 中 ID、拼音、释义、干扰项、图片资源名和音频路径不变。
- 照片保留宽高比，长边缩为 1024px，转换为 RGB PNG；OpenMoji 插画保持 618px RGBA。使用 drawable-nodpi，
  不引入密度缩放。同名矢量资源移除，动态资源保留规则继续生效。
- 真人字音规范化音量（目标 -18 LUFS / -2 dBTP），转换为 44.1kHz 双声道 Ogg
  Vorbis；上述三个音节按登记边界截取。处理方式、边界淡出和尾部静音写入 changes，不合成、不变调、不变速。
- 文件下载仅发生在素材准备阶段；运行时仍完全离线，不增加网络权限或依赖。
- 不把相似拼音文件名当成词义证明，例如 Zh-gou.ogg 是 gōu，不是狗 gǒu。
- 来源文字与目标文字不同时必须明确说明复用关系；同音复用的声调也必须一致。
- make_placeholder_audio.sh 仅填充缺失文件，避免覆盖已替换的真人录音。

## 维护检查

```sh
python3 -m unittest discover -s tools -p 'test_*.py' -v
python3 tools/validate_content.py
python3 tools/validate_content.py --require-real-media
python3 tools/validate_content.py --require-real-media --skip-rights-checks
```

普通校验检查已登记资源并显示全量登记覆盖数；完整性模式（沿用 --require-real-media 名称）
要求全部主题、字词和文化内容均有已登记的非占位配图及音频，明确区分照片与插画。
--skip-rights-checks 仍只跳过版权审核，不跳过资源、校验和、计数和内容一致性检查。
版权审核不是本作业的 CI 门槛；保留旧音频待审核事实，不据此宣称全部真人或许可已认证。
校验包括资源引用、PNG 头和尺寸、重复资源、文件 SHA-256、原字/目标字/声调对应，
以及需署名素材是否有应用内署名、音节截取元数据、数字拼图数量与非重叠区域。
待审核素材不能通过，Pexels 仅接受官方来源域名和许可地址。它不能证明真人身份、发音标准或完整解码，
也不能代替真机显示与播放检查。新增素材应先核验来源描述、试听/转写和图片内容，
再检查解码与最终 APK 中的资源。更新文件时同步更新清单和署名。
