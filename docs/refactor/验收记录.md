## 复现

```sh
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:assembleDebugAndroidTest :app:lintDebug
python3 tools/validate_content.py --require-real-media --skip-rights-checks
python3 tools/contrast_check.py
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb install -r app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb shell pm grant com.littlestar.app.debug android.permission.POST_NOTIFICATIONS
adb shell am instrument -w com.littlestar.app.debug.test/androidx.test.runner.AndroidJUnitRunner
```

提醒调度探针要求授予通知权限，实测确认请求已交给 AlarmManager。提示通知被系统禁用的用例需撤销该权限再单独运行。

在独立模拟器上先用旧版 Debug 完成一课并设置 PIN 和提醒。保留应用数据，用相同 Debug 签名执行 `adb install -r`，检查首页进度、用旧 PIN 打开新版家长区，并比较升级前后的学习记录、当日计划、首答和设置。另以强制停止模拟进程退出，重开后检查未完成的首课是否能继续。

## 覆盖边界

- 设备范围为 Android API 37 x86_64 模拟器，飞行模式运行；没有覆盖 API 30、ARM 真机或不同签名的 Release 升级。
- 设备自动化验证发音触发、媒体状态和播放位置，未验证扬声器可闻性、音质或真实设备上的提醒交付时间。
- 版权来源审核按项目约定跳过；内容校验不构成授权结论。
- Debug APK：`app/build/outputs/apk/debug/app-debug.apk`，不提交到 Git。
