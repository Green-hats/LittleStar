# LittleStar 项目设计书

## 谁在用

孩子 3–6 岁，在英语环境中长大，可能不认英文也不认汉字。打开 App 即可学习，家长设置不阻塞首课。家长从首页锁形入口设置每日目标和提醒，离开设置后重新进入须验证 PIN。无登录、网络、排行榜或广告。

参考多邻国的短回合、关卡顺序和即时反馈，参考洪恩识字、悟空识字的看图听音与辨认练习；不复制角色、画面、文案或声音。采用原创「星芽小径」：奶白地面、深紫主按钮、青绿进度、暖黄星点、圆润卡片和原创星迹插图。已有教学音频和可用内容配图继续服务教学，不沿用旧页面的硬影和印章外观。

## 首页到第一节课

1. 学习首页上方是今天，下面用「认识 → 练习 → 完成」标记短课顺序。孩子只需按一颗大按钮；正在进行的课显示 Continue lesson，今日目标达到后可主动复习。目标高于单轮上限时，拆成多轮。
2. 看图卡片突出插图、汉字及扬声器；英文含义和拼音为辅助。听当前字后按 Next，逐字认识；首次进入当天的第一张卡保留自动读音，扬声器可无限重听。词库浏览仍可主动标记学会。
3. 进入 Listen & choose，自动读题，并有重听。汉字选项不显示英文答案；有意义的图像作为非阅读线索。答对显示肯定提示。答错后显示目标字、英文含义和提示音；进入重试后不再展示答案，必须选对才可前进，不扣分、不设倒计时。
4. 完成页肯定探索和纠正，返首页或看逐题记录；错题不计作首答正确，次日优先巩固。完成前退出，今日入口可以恢复进行中的课；首页显示真实已学数量，不把完成回合和学会字数混为一谈。

## 页面和导航

首页是学习入口；Words 和 Culture 入口在同一导航带，子页面只显示当前位置和返回，不在答题途中呈现全局切换。系统返回不创建新首页或启动播放器。

| 责任 | 页面 | 内容和去向 |
|---|---|---|
| 共 | Learn 首页及加载/空态 | 今日目标、三阶段小径、继续/复习、Words、Culture、Parents |
| A | Word Gardens → Words | 按主题看进度 → 点字看图卡；可独立练主题 |
| A | Meet the words → Listen & choose | 每屏一张图卡；下一张 / 去练习；按题作答、即时反馈、重试 |
| C | Lesson complete → Round review | 首答与需巩固信息、返回首页、逐题作答和重听 |
| B | Culture → 分类列表 → 作品详情 | 儿歌、故事、古诗；列表可直接播放，详情看英中标题、简介、学习点、展开文本 |
| B | Now playing | 英中标题、插图、播/暂停、上一首/下一首、进度/歌词；离开不擅自暂停或开启播放 |
| C | Grown-ups → Learning plan | 创建/验证 PIN；目标 1–10、提醒开关、星期、时间、词义提示、音效；菜单保留帮助、关于、测试提醒 |

## 无障碍和语言

英文负责导航、操作、状态和家长设置；汉字、原文及普通话音频用于教学，拼音不是英文释义。重要操作配图标和可见英文（不能只靠颜色或隐藏说明）。儿童触控目标优先 56dp，所有操作至少 48dp；文本跟随系统字号，小屏和长内容纵向滚动，主要按钮不依赖横滑。保留固定浅色；识字卡横屏遵从当前要求，仅提示转回竖屏。
