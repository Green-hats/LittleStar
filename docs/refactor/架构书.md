# LittleStar 架构书

## 边界

基线：`main` 的 `f034350`。保持单一 Gradle 应用、Java 17、XML/ViewBinding、现有 SDK 和 app ID。主题由 Material 3 浅色令牌、Material 按钮/卡片/输入控件及可复用样式实现；不引入 Compose 或 Kotlin 源码。

| 层 | 职责与依赖 |
|---|---|
| `feature/home` 与 `core/ui` | 首页导航、原创视觉、字号和窗口内边距；接收 ViewModel 状态，不接触磁盘文件 |
| A：`feature/words, flashcard, quiz` | 词库、识字卡、听音作答；只传主题 ID、会话 ID 和必要的入口参数 |
| B：`feature/culture, player` | 按 ID 读本地作品，组织同分类播放队列；仅显式播放动作启动音频 |
| C：`feature/parent, settings, reward, review` | PIN、设置、完成与回顾；以会话 ID 读取持久化首答，不把个人报告塞入代码 |
| `domain` | 每日计划、短课切分、题目生成、复习间隔；时间由 AppClock 提供，测试可注入 |
| `data` | 内容资产索引、学习仓库、原子进度文件及设置；页面不直接读写文件 |
| `playback` / `notify` | Media3 会话与通知控制、离线音频和家长排程；与识字计数隔离 |

保留团队原有 13 个 Activity 的责任边界，替换可见界面和进入顺序；保留纯逻辑、内容、播放和提醒基础设施。Activity 负责绑定、导航与生命周期；ViewModel 保存派生状态、处理交互，底层数据通过 AppContainer 注入。内部页面不导出，家长设置在 Activity 边界检查解锁。列表的返回栈恢复位置，不重新发起播放。

## 进度与课中恢复

- 继续使用 `files/progress.json`：`words`（首次学会时间、复习盒、到期日、首答计数），`dailyPlans`（本地日期、目标、字 ID），`sessions`（ID、类型、顺序、作答及完成时间）。`settings` 保存原 PIN 验证材料、设置和首次使用标记。
- 保留现有 schema v3；1→2→3 旧迁移仍有效。新增会话字段须可选并以缺省值读取；不更换文件路径、词 ID、包名或签名。旧会话缺少可选字段时以原答题记录推断或安全回到本课开头，已学字和答案不清空。不同签名或不同 build variant 不能直接覆盖安装。
- 写入经单一磁盘执行器和 AtomicFile。每日计划一旦生成，当日不重建；继续课优先寻找未完成且内容有效的当日每日/复习会话。答题以会话和字 ID 去重，重试答对才解锁下一题，不把一次纠正变成第二条首次答题或提高复习盒。
- 错题在首答时排到次日复习；纠正成功后保留该状态。已有成功记录的字不因答错而丢失。完成写入后从同一会话派生首页与回顾。静态内容随 APK 打包；不新增 INTERNET 权限，保留动态配图 keep 规则。

## 验证边界

| 层 | 方法 |
|---|---|
| 逻辑与数据 | JUnit：计划、旧版迁移与 JSON 回读、首次答错与纠正如何影响进度、未完成课恢复、完成去重、PIN 设置 |
| 静态与构建 | Debug APK、Lint、Python 内容测试/真实媒体校验/主题对比度；检查 Java 源码、merged manifest、APK 权限 |
| 设备 | 模拟器安装旧版并产生记录后覆盖安装；飞行模式走首课、错题重试、恢复、回顾、文化播放和 PIN；检查小屏、大字体、无障碍及返回 |
| 交付声明 | 记录环境、命令和结论；分别标记播放器状态和实际可闻、模拟器和物理设备、计划与已执行结果 |
