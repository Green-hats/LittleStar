# 页面语言分工

面向英语环境中学习中文的 3–6 岁儿童：**英文负责定位、操作和理解；中文负责教学。** 不要求孩子先认中文才能使用应用，也不把教学内容全部改成英文。

## 不可退化的规则

1. 每个应用页面及加载、空白、错误、暂停状态都需要可见的英文定位或操作提示；应用名称、时长、图标、拼音和隐藏的 contentDescription 不能单独算英文支持。
2. 导航、按钮、操作说明、状态、反馈、错误、权限解释及家长设置使用英文。中文单字可以作为装饰或教学标记，但不能是唯一操作标签。
3. 学习材料保留中文原字、原名、原文和中文音频；提供英文含义/标题/说明。拼音只辅助发音，不能代替英语含义。
4. 文化作品需 `titleEn`、`subtitleEn`、英文简介和学习重点；儿歌/古诗的每句需汉字、拼音和英文；无逐句歌词的故事需 `transcriptEn`。
5. 测验不在汉字选项下放英文答案，也不默认开启词义提示。指令始终英文；答后解释与本轮回顾支持理解，保留已有学习设置语义。
6. 英文标题和中文原名分层显示，不把所有内容塞进固定高度的一行。新增文字需检查换行、小屏和大字体。窄列中的短操作标签保持完整单词，按可用宽度在12–16sp间适配，模块标题上限22sp（仍跟随系统字体缩放）；装饰字徽章适配固定容器，分类卡片随正文高度增长，不缩小教学正文或汉字卡来规避大字体。
7. 英语文字不能被误解为新增英文配音；音频依然是中文。故事梗概明确不是逐字字幕，英文诗歌/歌词是含义辅助，不声称是押韵改编或音轨逐词翻译。
8. 英文帮助尚未独立阅读英文的幼儿降低门槛，但不保证 3 岁儿童能独立读完所有梗概；仍需图片、中文朗读、直观图标及家长共读。系统权限对话框、软键盘和系统设置由 Android 控制，语言遵循系统，应用不伪造或覆盖它们。

## 逐页矩阵

学习状态统一使用 `recorded`（学习记录），不表示掌握：手动记录或首次答对都可能建立记录，底层 `learnedAt` 和复习调度保持兼容。词卡底部只显示当前流程和去向；错题纠正不修改首次成绩或学习计划。封面负责作品识别，英文负责操作，代表汉字继续承担教学提示。

| 页面/状态 | 中文保留在哪里 | 必须可见的英文 | 本次处理 |
|---|---|---|---|
| 首页 · Words | 今日字 | Browse words / Listen & read、进度、拼音以外的单词含义、START/REVIEW | 原“字/文”模式切换改为英文；卡片改顺序流布局，英文可换行 |
| 首页 · Culture | 推荐字、作品中文名 | 英文作品名、Today · Culture、EXPLORE | 不再用中文类别填入英文栏；使用 titleEn |
| 首次引导两步 | 不要求中文识字 | 年龄/目标说明、Next/Skip、提醒说明与允许/稍后 | 保持完整英文引导，不改系统权限页 |
| Themes | 主题中文名和代表字 | Pick a theme、Animals 等主题名、顺序及进度 | 保留已有中英双层主题 |
| WordList | 汉字 | 主题英文、各词含义、操作提示、Quiz | 保留每词汉字+拼音+英文 |
| Flashcard（学习/浏览） | 大字、会字教学标记 | 词义、Listen/NEXT/DONE、可选标记说明、音频失败重试/返回 | 中文标记不作唯一操作说明；已有英文标签保留 |
| Quiz（作答/反馈/音频失败） | 汉字选项；答后拼音 | Quiz、Listen & choose、Correct/错误解释、NEXT/DONE、失败处理 | 错误反馈加入目标字英文含义；不向选项添加英文答案 |
| Reward | 本轮字块 | Great job!、练习数量、Done!、Review this round、完成/重练 | “learned”改“practiced”，徽章不再独立用“学会”声称掌握 |
| RoundReview（有记录/空态） | 每题汉字及选择记录 | 单词含义、correct/答案解释、得分、空态 | 保留已有中英对照与英文空态 |
| CultureCategories | 中文类别与代表字 | Songs / Stories / Poems、数量、Pick one | 保留中英标签，不用汉字代表全部导航 |
| CultureList | 作品中文原名与代表字、类别中文 | 英文分类页名、每项英文作品名、Song/Story/Poem及作者、时长 | 补全部11项英文标题/类型作者；行高自适应 |
| CultureDetail（加载/无效ID/展开） | 原名、大字、原文 | Discover、英文作品名、类型作者、简介、Listen for、Read together、LISTEN、加载/不可用 | 儿歌/古诗按“汉字→拼音→英文”逐句共读；故事补完整英文梗概并标明非逐字字幕 |
| Player（开始前/播放/暂停/无歌词/切歌） | 原名、代表字、歌词 | 顶部英文作品名；初始 Listen & learn；英文简介、类型作者；可见 Previous/Play或Pause/Next；当前句英文 | 不依赖歌词出现才有英文；故事和暂停状态也保留英文；通知 metadata 同步英文名和中文原名 |
| ParentGate（创建/确认/错误/验证） | 无需中文 | Parents only、PIN指令、确认/不匹配提示、OK | 保持全英文；不能要求孩子读懂“家长”才能认出受限区 |
| Settings（保存/取消/提醒阻断） | 无需中文 | Learning plan、目标与提醒说明、星期、Save/Cancel、阻断提示 | 保持英文；时间选择器标题、确认和取消显式使用应用英文文案 |
| 帮助/关于/测试通知/系统媒体控件 | 素材原名、合法署名保留原文；媒体中文原名 | 帮助说明、About、版本、测试反馈、通知英文；曲目英文名 | 不翻译或破坏署名；应用自有确认按钮用英文资源 |

这里的 13 个正式 Activity 不包括首启覆盖层、帮助/关于对话框、时间选择器和通知，但语言检查包含这些状态。

## 内容与回归

- `tools/validate_content.py --skip-rights-checks` 同样强制技术层英文支持：主题/分类名、单词含义、作品英文名/类型、简介/学习重点、逐句英文、故事英文梗概。此参数不会跳过语言要求。
- 校验器只能发现缺字段、空白和没有拉丁文字等问题，不会判断一段文字是否是准确、自然、适龄的英语；翻译质量仍需人工审阅。
- JVM 测试校验真实内容与中拼英阅读组合；Python 测试防止上述字段退化；`LanguageSupportTest` 检查首页切换、全部文化列表/详情和无歌词故事播放器的英文支持。
- UI 验收需另看英文是否真的可见、大小合适、有换行、是否被遮挡，而非仅看字符串存在。应用固定浅色；涉及布局时检查系统主题切换后仍保持浅色、360×640dp 和大字体；没有执行的配置不得写成通过。

本次不改变中文音频、教学字形、素材来源记录、每日计划和作答规则。
